# 🤝 Character Killing Monuments BR Edition - Contributing Guide

> Guidelines for contributing to the project.

> Guia para contribuir com o projeto.

---

# 📖 Introduction

## English

Thank you for your interest in contributing to Character Killing Monuments BR Edition.

This project exists because developers from the Lineage 2 community shared knowledge, code and improvements throughout the years.

All contributions are welcome, but they must respect the project's history, organization and original credits.

## Português

Obrigado pelo interesse em contribuir com o Character Killing Monuments BR Edition.

Este projeto existe porque desenvolvedores da comunidade Lineage 2 compartilharam conhecimento, código e melhorias ao longo dos anos.

Todas as contribuições são bem-vindas, mas devem respeitar a história, organização e créditos originais do projeto.

---

# 📌 Before Contributing

Before submitting any change:

- Read the project documentation.
- Check existing issues.
- Understand the project structure.
- Respect original credits.
- Keep code organized.

Antes de enviar qualquer alteração:

- Leia a documentação do projeto.
- Verifique issues existentes.
- Entenda a estrutura do projeto.
- Respeite os créditos originais.
- Mantenha o código organizado.

---

# 🐛 Reporting Bugs

When reporting a bug, provide:

- Description of the problem.
- Steps to reproduce.
- Server revision.
- Java version.
- Error logs.
- Screenshots if applicable.

Example:
Problem:
Monument does not update player appearance.

Environment:
Public_Brproject
Java 25

Logs:
Paste error here.

---

# 💡 Suggesting Features

Feature suggestions should include:

- Description.
- Reason for the improvement.
- Possible implementation idea.
- Expected behavior.

---

# 🔀 Pull Requests

Before creating a Pull Request:

- Make sure the code compiles.
- Test your changes.
- Explain what was changed.
- Update documentation when necessary.

---

# 📝 Commit Guidelines

This project follows Conventional Commits.

Examples:
feat: add monument ranking system

fix: correct player appearance synchronization

docs: update installation guide

refactor: improve manager structure

---

# 🧹 Code Style

Contributions should:

- Follow the existing project style.
- Avoid unnecessary changes.
- Keep methods readable.
- Remove debug code before submission.

---

# ❤️ Respect for Original Work

Character Killing Monuments BR Edition recognizes and respects all previous contributors.

Original credits must never be removed.

---

# 📌 Final Note

The goal is not only to add features.

The goal is to maintain a stable, organized and respectful project for the Lineage 2 community.
