# 🔒 Security Policy

> Security information for Character Killing Monuments BR Edition.

> Informações de segurança do projeto.

---

# 📖 About

## English

Character Killing Monuments BR Edition is a community project focused on Lineage 2 server development and compatibility improvements.

Security reports are taken seriously and should be reported responsibly.

## Português

O Character Killing Monuments BR Edition é um projeto comunitário focado em desenvolvimento de servidores Lineage 2 e melhorias de compatibilidade.

Relatórios de segurança devem ser enviados de forma responsável.

---

# 🚨 Reporting a Security Issue

If you find a security vulnerability:

Please do not create a public issue.

Instead, contact the project maintainer privately.

Provide:

- Description of the vulnerability.
- Steps to reproduce.
- Possible impact.
- Relevant logs or examples.

---

# 🛡️ Scope

Security concerns may include:

- Unauthorized access.
- Data exposure.
- Database vulnerabilities.
- Exploitable server behavior.
- Critical code issues.

---

# ⏱️ Response

Reports will be reviewed as soon as possible.

The project will evaluate:

- Severity.
- Impact.
- Possible fixes.

---

# ❤️ Responsible Disclosure

We appreciate responsible reports that help improve the project.

Security improvements will be documented when applicable.
