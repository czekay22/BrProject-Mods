# 🇧🇷 Introdução

O Character Killing Monuments BR Edition nasceu com o objetivo de preservar e modernizar um sistema clássico da comunidade Lineage 2 Java.

Antes de ser uma adaptação, este projeto é uma continuação de uma ideia criada anos atrás por desenvolvedores da comunidade L2J.

A proposta sempre foi simples:

Criar monumentos dentro do jogo capazes de representar os maiores guerreiros do servidor, exibindo jogadores com destaque nos rankings de PvP e PK.

---

# 📜 Origem do Character Killing Monuments

## English

The original Character Killing Monuments system was created by **Paytaly** and published on the **L2JBrasil** forum in 2015.

The original work introduced the concept of representing top PvP and PK players through in-game monuments.

Later, **Lopes Netinho** adapted the project for L2J Frozen revisions, keeping the original credits to Paytaly and making the system available for a new generation of Lineage 2 server developers.

## Português

O sistema original Character Killing Monuments foi criado por **Paytaly** e publicado no fórum **L2JBrasil** em 2015.

O trabalho original trouxe o conceito de representar os jogadores com maior destaque em PvP e PK através de monumentos dentro do jogo.

Posteriormente, **Lopes Netinho** realizou uma adaptação do projeto para revisões L2J Frozen, mantendo os créditos originais de Paytaly e permitindo que o sistema continuasse sendo utilizado por novos desenvolvedores de servidores Lineage 2.

# 🔄 Evolution Through L2J Revisions

## L2J Frozen

# 🚀 Character Killing Monuments BR Edition

## The Beginning

O Character Killing Monuments BR Edition surgiu através da necessidade de adaptar o sistema para o **Public_Brproject**, uma revisão moderna baseada em L2J Interlude.

Durante o processo de adaptação foram encontrados diversos desafios relacionados a:

- Estrutura de classes moderna;
- Alterações nos packets;
- Sistema de NPC;
- Polymorph;
- Fake Player;
- Atualização visual dos monumentos;
- Compatibilidade com Java 25.

---

# 🛠 Modernization Goals

O objetivo desta versão não é substituir o trabalho original.

O objetivo é continuar sua evolução.

As principais metas são:

- Manter os créditos do autor original;
- Melhorar a organização do código;
- Documentar o funcionamento do sistema;
- Facilitar instalações futuras;
- Melhorar compatibilidade;
- Permitir manutenção contínua.
