# 📌 Versioning

This project uses Semantic Versioning:
MAJOR.MINOR.PATCH

Example:
1.0.0

Meaning:

- MAJOR: Breaking changes or major redesigns.
- MINOR: New features and improvements.
- PATCH: Bug fixes and small corrections.
