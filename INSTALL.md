# 📦 Installation Steps

## Step 1 - Backup

Before installing any modification:

- Create a backup of your server files.
- Create a database backup.
- Keep your original files safe.

---

## Step 2 - Source Installation

Copy the required source files into your server project.

The files and locations will be documented according to each release.

---

## Step 3 - Database Installation

Execute the required SQL files.

SQL files will be available inside:

sql/

---

## Step 4 - Configuration

Enable and configure the required settings.

Configuration details will be documented here.

---

## Step 5 - Compile

Compile your server project using:
IntelliJ IDEA

Make sure there are no compilation errors before starting the server.

---

## Step 6 - Testing

After installation:

Verify:

- Server startup.
- Monument spawn.
- PvP ranking.
- PK ranking.
- Player appearance synchronization.

---

# 🔄 Updating

When a new version is released:

1. Read the CHANGELOG.md.
2. Backup your current installation.
3. Apply the update files.
4. Execute required SQL updates.
5. Recompile the server.
6. Test the system.
